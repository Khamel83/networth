# Monthly Pairing Priority

The monthly matcher will apply hard exclusions first, use the Natalie/Ashley admin-flex rotation for the normal odd-roster case, maximize the number of eligible Players assigned, maximize fresh pairings whenever a complete fresh assignment is possible, then prefer performance-similar pairings, with deterministic tie-breaking. New players begin in a neutral pool and are preferred with other new players when feasible; otherwise they are assigned to the closest available measured player. This keeps the league's no-play-again and coverage rules authoritative while using the same monthly match-result data to improve pairing quality for a dynamic roster; only a genuinely infeasible compatibility graph may leave someone unpaired or require a forced repeat, and it does not promise that every match will be close.
